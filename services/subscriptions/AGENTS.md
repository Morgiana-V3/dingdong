# Node 服务器订阅项目

- 先阅读 README.md。此项目复用 Studio 的 B 站、贴吧、X、小红书和统一推送插件；保持 vendor 源码可追溯，并区分自动化适配验证与真实平台验证。
- 保持 Cordis 插件、会话存储、HTTP 管理接口和 Web UI 职责分离。
- 真实账号登录及验证码由用户完成；不得把匿名页面显示成功描述为账号登录成功。
- 不输出或提交 data/、配对码、管理密钥、Cookie、浏览器存储、用户内容和现场截图。
- 默认回环监听；远程测试通过 SSH 转发。不取消认证、同源检查、一次性配对和浏览器导航限制。
- 登录态只有在服务端账号与采集验证通过后才持久化；明确区分手机登录与 Web 备用路径的结果。
- 运行 npm test；修改 Web 交互后检查真实浏览器页面。
